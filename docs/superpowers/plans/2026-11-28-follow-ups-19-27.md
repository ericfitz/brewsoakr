## Review Focus

1. Names that are not plain words at the lock: `python@3.12`, `c++filt`, a file in a nested directory. The lock file is `<name>.formula.lock` for the file's stem; a name with `/` or NUL is refused, not sanitized (Task 3).
2. A lock file that is a symbolic link, a lock directory that does not exist, and a lock file brew unlinks between open and lock. The first is refused, the second is created, the third is retried (Task 3).
3. The stale inventory: a formula the inventory says is not from the soak tap whose receipt on disk now names it. Prune must keep its file (Task 3).
4. `upgrade --cask` on a machine with an anchored formula: its tap file must survive the start-of-run prune (Task 5).
5. A keg copy or tap file that does not parse: `from_tap_at` must answer no, never treat two `None` versions as equal (Task 2).
6. A `version :latest` cask: its receipt says `latest`; the label of Task 6 must not fire for it and Task 2 must ask the receipt for `latest`.
7. Output that tests elsewhere pin: the count of `brew does not trust tap` lines (Task 7), the reason `its receipt does not name brewsoak's tap` (Task 2), `X -> X` dependency lines (Task 6).

```rust
pub fn from_tap_at(
    brew: &impl Brew,
    kind: PkgKind,
    name: &str,
    version: Option<&str>,
    file: Option<&[u8]>,
) -> bool {
    let names_soak = |tap: Option<String>| {
        tap.is_some_and(|t| crate::origin::own_tap(&t) == Some(OwnTap::Soak))
    };
    let parsed = file.and_then(|f| file_version(kind, f));
    let asked = version.map(str::to_string).or_else(|| parsed.clone());
    let exact = asked.is_some_and(|v| {
        let v = if kind == PkgKind::Cask && v == ":latest" { "latest" } else { v.as_str() };
        names_soak(brew.receipt_tap(kind, name, v))
    });
    if exact || kind != PkgKind::Formula {
        return exact;
    }
    let Some(want) = parsed else {
        return false;
    };
    brew.soak_tap_keg_files(name)
        .iter()
        .any(|rb| file_version(kind, rb.as_bytes()).as_deref() == Some(want.as_str()))
}
```

Reference implementation of the lock:

```rust
pub fn try_brew_formula_lock(locks_dir: &Path, name: &str) -> Result<BrewLock, BrewLockError> {
    use std::os::unix::fs::MetadataExt;
    let unavailable = |why: String| BrewLockError::Unavailable(why);
    if name.is_empty() || name == "." || name == ".." || name.contains(['/', '\0']) {
        return Err(unavailable(format!("{name:?} is not a formula name")));
    }
    std::fs::create_dir_all(locks_dir).map_err(|e| unavailable(e.to_string()))?;
    let path = locks_dir.join(format!("{name}.formula.lock"));
    // brew unlinks lock files in `brew cleanup`, so the file that was locked
    // must still be the one at the path (brew's own check, `lock_file.rb`).
    for _ in 0..3 {
        if std::fs::symlink_metadata(&path).is_ok_and(|m| m.file_type().is_symlink()) {
            return Err(unavailable("the lock file is a symbolic link".into()));
        }
        let file = OpenOptions::new()
            .read(true)
            .write(true)
            .create(true)
            .truncate(false)
            .open(&path)
            .map_err(|e| unavailable(e.to_string()))?;
        match file.try_lock() {
            Ok(()) => {}
            Err(TryLockError::WouldBlock) => return Err(BrewLockError::Busy),
            Err(TryLockError::Error(e)) => return Err(unavailable(e.to_string())),
        }
        let same = match (file.metadata(), std::fs::metadata(&path)) {
            (Ok(a), Ok(b)) => a.ino() == b.ino() && a.dev() == b.dev(),
            _ => false,
        };
        if same {
            return Ok(BrewLock { _file: Some(file) });
        }
    }
    Err(BrewLockError::Busy)
}
```

- `ProcessBrew::lock_formula`: the directory is `$(brew --prefix)/var/homebrew/locks`, from `self.brew_dir("--prefix")`, asked once per run (`locks` cell). No directory: `Unavailable("brew --prefix gave no directory")`.
- `MockBrew::lock_formula`: push the name to `lock_calls`; `Busy` when it is in `busy_formulae`; `Unavailable(text)` when `lock_error` is set; else `Ok(BrewLock::unguarded())`.
- `prune` keeps its first test (`used`: an undo entry, or the inventory says the receipt names the soak tap) and takes no lock for a file that test keeps. For each remaining `.rb`, with `name` the file's stem and `path` the file:
  - **Formula:** `brew.lock_formula(name)`.
